

# Student Progress Tracking System

A web-based system that helps students track their academic progress, assignments, courses, and study goals.

## Features
- Student Dashboard
- Course Management
- Assignment Tracking
- Study Planner
- Academic Goals
- Progress Analytics

## Technologies
- HTML
- CSS
- JavaScript
- Supabase (Backend)

## Installation
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Create an account to get started.

## Target Users
University and college students.
